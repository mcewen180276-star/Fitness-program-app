Fitness Programme Manager v50 — Calculators & Client Technique Links

Upload ALL extracted files and the icons folder to the same GitHub Pages repository as before. Make an encrypted backup first.

Calculators:
- Load selected client measurements or enter manually. Manual edits never change the client's consultation profile.
- Save calculator inputs separately for each client (or manual mode).
- Age-based estimated maximum HR (208 - 0.7*age), optional measured maximum, %max and heart-rate reserve (Karvonen), 5 zones and training use.
- Adult BMI, BMR estimate range, waist-to-height ratio, cardio pace/speed, estimated 1RM with approximate % load bands, session-RPE training load, optional measured body fat.
- Trainer-confirmed Add to Programme buttons append selected targets to the first non-rest session focus. Existing sessions remain intact; printouts and Client Companion show the focus.
- Client Companion exercise demonstration links are labelled more clearly; they use validated HTTPS URLs or a YouTube technique search fallback when no specific demo exists. They require internet access to open.

Limitations: zones, BMI, BMR and 1RM are estimates and should be interpreted with clinical/trainer judgement. Manual values are not synced back to the client questionnaire. Session references must be added to a selected client's active programme. This is a free offline-first PWA; internet is needed for demo links.
